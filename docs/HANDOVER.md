- Макеты и дизайн-система: см. [DESIGN.md](DESIGN.md)

## Как обновить сайт
1. Измените файл (текст в `index.html`, фото в `assets/img/`).
2. В репозитории: Add file → Upload files (или значок карандаша у файла) → Commit changes.
3. Через 1–2 минуты обновите страницу через Ctrl+F5.

## Свой домен
1. Купите домен (`.ru` или `.рф`) у регистратора.
2. В Settings → Pages → Custom domain впишите домен и включите Enforce HTTPS.
3. Добавьте у регистратора четыре A-записи (`185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`) и CNAME для `www` на `steelykt.github.io`.
4. Замените адрес сайта в `og:url`, `og:image`, JSON-LD, `robots.txt` и `sitemap.xml`.

## Аналитика
Добавьте код Яндекс Метрики перед `</head>`, баннер согласия на cookie и цели: нажатия на Telegram, WhatsApp, Instagram и завершение самопроверки.

## Ограничения
- Сайт статический, формы отправки нет: запись только через мессенджеры.
- GitHub Pages иногда работает нестабильно из России. Запасные варианты: Cloudflare Pages, Netlify, российский хостинг.
