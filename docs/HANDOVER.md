# Передача проекта заказчику

## Адреса
- Сайт: https://steelykt.github.io/psychologist-site/
- Репозиторий: https://github.com/steelykt/psychologist-site
- Макеты и дизайн-система: см. [DESIGN.md](DESIGN.md)

## Как обновить сайт
1. Измените файл (текст в `index.html`, фото в `assets/img/`).
2. В репозитории: Add file → Upload files (или значок карандаша у файла) → Commit changes.
3. Через 1–2 минуты обновите страницу через Ctrl+F5.

## Свой домен
1. Купите домен (`.ru` или `.рф`) у регистратора.
2. В Settings → Pages → Custom domain впишите домен и включите Enforce HTTPS.
3. Добавьте у регистратора четыре A-записи (`185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`) и CNAME для `www` на `steelykt.github.io`.
4. Замените адрес сайта в `og:url`, `og:image`, JSON-LD, `robots.txt` и `sitemap.xml`.

## Настройки в `assets/js/main.js` (блок `CONFIG` в начале файла)
| Параметр | Что делает |
|---|---|
| `MAX_URL` | Ссылка на профиль в MAX (указана). Пустое значение скрывает кнопку; когда заполнено, MAX заменяет WhatsApp в нижней панели на телефоне |
| `PRIMARY` | Главный канал: `'max'` или `'tg'`. Главный стоит первым и выделен заливкой |
| `VK_URL` | Ссылка на страницу в VK (сейчас `https://vk.ru/byolgaokhlopkova`). Пустое значение скрывает кнопку |
| `METRIKA_ID` | Номер счётчика Яндекс Метрики. Пока 0, цели не отправляются |
| `RESULTS_ENDPOINT` | Адрес Google Таблицы для обезличенной статистики подбора (без имён и контактов), см. [RESULTS_TABLE.md](RESULTS_TABLE.md) |
| `PRIVACY_URL` | Страница политики. Вместе с адресом включает форму «Оставить контакт» |
| `CONTACT_FORM_URL`, `CONTACT_FORM_FIELDS` | Российская альтернатива: форма в Яндекс Формах. Подробности в [RESULTS_TABLE.md](RESULTS_TABLE.md) |

## Аналитика
1. Добавьте код счётчика Яндекс Метрики перед `</head>` и укажите его номер в `METRIKA_ID`. Нужен баннер согласия на cookie.
2. Создайте в Метрике цели с этими идентификаторами (тип «JavaScript-событие»): `tg`, `tel`, `wa`, `ig`, `max`, `vk` (кнопки в контактах), `tg_bar`, `tel_bar`, `wa_bar`, `max_bar` (нижняя панель), `breath_start`, `breath_done`, `quiz_start`, `quiz_done`, `quiz_cta`, `quiz_sent`.
3. В `quiz_done` уходят тема и рекомендованный формат как параметры визита, их видно в отчёте по параметрам без передачи персональных данных.
4. Для сравнения каналов ставьте метки в ссылки: например, в био Instagram `https://steelykt.github.io/psychologist-site/?utm_source=instagram`.

## Ограничения
- Сайт статический. Запись через мессенджеры и по телефону; отправка результатов подбора в таблицу по умолчанию выключена (см. [RESULTS_TABLE.md](RESULTS_TABLE.md)).
- WhatsApp и Instagram в России недоступны без VPN, поэтому главной кнопкой остаётся Telegram, а рядом есть звонок. Порядок кнопок стоит пересматривать по целям Метрики.
- GitHub Pages иногда работает нестабильно из России. Запасные варианты: Cloudflare Pages, Netlify, российский хостинг.
