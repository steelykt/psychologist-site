# Статистика подбора в Google Таблице: сколько человек и с какими запросами

Решение: считаем **только обезличенную статистику**. Имён, телефонов и других контактов сайт не собирает и в таблицу не отправляет.

## Что попадает в таблицу
После каждого прохождения подбора добавляется одна строка:

| Столбец | Пример |
|---|---|
| Дата | 26.11.2026 14:32 |
| ID | случайный код прохождения (нужен, чтобы повторная отправка не задвоила строку) |
| Тема | Тревога, напряжение, стресс |
| Где ощущается | В теле и сне |
| Как давно | Больше полугода |
| Насколько мешает | Часто мешает |
| Чего ждёт | Научиться справляться в целом |
| Формат встреч | Онлайн |
| Рекомендовано | Серия встреч |
| Источник | `utm_source=instagram` (если ссылка с меткой) |

Это всё. Ни имени, ни контакта, ни IP-адреса в строке нет, а скрипт ниже в принципе не умеет сохранять контакты.

## Настройка (около 10 минут)
1. Создайте Google Таблицу (название любое).
2. Откройте Расширения → Apps Script и вставьте код ниже вместо содержимого.
3. Нажмите «Развернуть» → «Новое развёртывание» → тип «Веб-приложение». Выполнять от своего имени, доступ «Все». Разрешите доступ к таблице, когда Google спросит.
   **Предупреждение «Google не проверил это приложение»** появляется всегда для собственных скриптов: проверка нужна только тем, кто публикует приложения для других людей. Нажмите «Дополнительные настройки» (Advanced) → «Перейти на страницу «…» (небезопасно)» → «Разрешить». Строка `@OnlyCurrentDoc` в начале скрипта ограничивает доступ одной этой таблицей, а не всем вашим Google Диском и другими таблицами.
4. Скопируйте адрес веб-приложения (заканчивается на `/exec`) и вставьте в `RESULTS_ENDPOINT` в начале `assets/js/main.js`.
5. `PRIVACY_URL` и `CONTACT_FORM_URL` оставьте пустыми: форма контакта не появится.
6. Пройдите подбор на сайте сами: в листе «Ответы» должна появиться строка. Если меняете код скрипта, делайте «Новое развёртывание» заново, иначе работает старая версия.

```javascript
/** @OnlyCurrentDoc */
var SHEET = 'Ответы';
var HEAD = ['Дата', 'ID', 'Тема', 'Где ощущается', 'Как давно', 'Насколько мешает',
            'Чего ждёт', 'Формат встреч', 'Рекомендовано', 'Источник'];

// Значения, начинающиеся с = + - @, Таблицы считают формулой: экранируем
function safe(v) {
  v = String(v == null ? '' : v).slice(0, 200);
  return /^[=+\-@]/.test(v) ? "'" + v : v;
}

function reply(t) { return ContentService.createTextOutput(t); }

// Для проверки: если открыть адрес /exec в браузере, появится эта надпись
function doGet() { return reply('Статистика подбора работает'); }

function doPost(e) {
  var lock = LockService.getScriptLock();
  lock.waitLock(10000);
  try {
    var d = JSON.parse(e.postData.contents);
    // принимаем только статистику с корректным кодом прохождения; контакты игнорируем
    if (d.kind !== 'stat' || !/^[a-z0-9]{8,40}$/.test(String(d.rid || ''))) return reply('ignored');

    var ss = SpreadsheetApp.getActive();
    var sh = ss.getSheetByName(SHEET) || ss.insertSheet(SHEET);
    if (sh.getLastRow() === 0) sh.appendRow(HEAD);

    // повторная отправка с тем же ID не создаёт вторую строку
    var n = Math.max(sh.getLastRow() - 1, 1);
    var found = sh.getRange(2, 2, n, 1).createTextFinder(d.rid).matchEntireCell(true).findNext();
    if (found) return reply('dup');

    sh.appendRow([new Date(d.ts), d.rid, safe(d.topic), safe(d.area), safe(d.duration),
                  safe(d.interference), safe(d.need), safe(d.meet), safe(d.recommend), safe(d.src)]);
    return reply('ok');
  } finally {
    lock.releaseLock();
  }
}
```

## Проверка до правки сайта
1. Откройте адрес `/exec` в браузере: должна появиться надпись «Статистика подбора работает». Ошибка про `doGet` значит, что в скрипте нет последней функции или развёртывание старое.
2. Откройте любую страницу сайта, нажмите F12 → вкладка «Консоль», вставьте строку с вашим адресом и нажмите Enter. В листе «Ответы» должна появиться строка с темой «Тест», её потом можно удалить:

```javascript
fetch('ВАШ_АДРЕС/exec', {method: 'POST', mode: 'no-cors', headers: {'Content-Type': 'text/plain;charset=utf-8'}, body: JSON.stringify({kind: 'stat', rid: 'test0001abcd', ts: new Date().toISOString(), topic: 'Тест', area: '', duration: '', interference: '', need: '', meet: '', recommend: '', src: ''})})
```

## Если строка не появляется
- Адрес должен заканчиваться на `/exec`, а не на `/dev`.
- В развёртывании доступ должен быть «Все», иначе запрос уйдёт на страницу входа Google.
- Меняли код скрипта: нужно «Управление развёртываниями» → карандаш → «Версия: новая версия» → «Развернуть», иначе работает старый код.
- Посмотрите журнал: в Apps Script слева «Выполнения», там видны ошибки каждой отправки.
- Блокировщик рекламы или сеть без доступа к Google на стороне посетителя: строка не дойдёт, это нормально для небольшой доли.

## Лист «Статистика»
Создайте второй лист и вставьте формулы. В русской локали разделитель аргументов `;`.

- **Сколько всего прошли подбор:** `=COUNTA(Ответы!B2:B)`
- **Запросы по темам:** `=QUERY(Ответы!A2:J; "select C, count(B) where B is not null group by C order by count(B) desc label C 'Тема', count(B) 'Человек'"; 0)`
- **Рекомендованный формат:** `=QUERY(Ответы!A2:J; "select I, count(B) where B is not null group by I label I 'Формат', count(B) 'Человек'"; 0)`
- **Тема и рекомендованный формат вместе:** `=QUERY(Ответы!A2:J; "select C, count(B) where B is not null group by C pivot I"; 0)`
- **Чего ждут от встреч:** `=QUERY(Ответы!A2:J; "select G, count(B) where B is not null group by G label G 'Ожидание', count(B) 'Человек'"; 0)`
- **По дням:** `=QUERY(Ответы!A2:J; "select toDate(A), count(B) where B is not null group by toDate(A) order by toDate(A) desc label toDate(A) 'День', count(B) 'Прошли подбор'"; 0)`
- **Откуда пришли:** `=QUERY(Ответы!A2:J; "select J, count(B) where B is not null group by J label J 'Источник', count(B) 'Человек'"; 0)`

## Как читать цифры
- «Сколько человек» это число завершённых подборов. Тот, кто прошёл дважды, посчитается дважды, а начавшие и бросившие в таблицу не попадают.
- Статистика приблизительная: если у посетителя Google недоступен, строка не дойдёт и он не посчитается. Сверяйте с целями Яндекс Метрики `quiz_start` и `quiz_done` (воронка: начали → дошли до результата).
- Ссылки с метками (`?utm_source=instagram`, `?utm_source=vk`, `?utm_source=max`) в био и постах покажут, откуда приходят люди.

## Что это значит для закона (коротко)
- Строка без имени, контакта и IP не позволяет определить человека, поэтому её обычно не считают персональными данными. Над подбором и под результатом всё равно честно написано, что ответы попадают в обезличенную статистику. **Это не юридическая консультация.**
- Если когда-нибудь появится сбор контактов, это другая ситуация: понадобятся политика, отдельное согласие, российское хранение и, по обзорам, уведомление в Роскомнадзор. Шаблон и порядок в [PRIVACY_TEMPLATE.md](PRIVACY_TEMPLATE.md), российские варианты хранения (Яндекс Формы, Яндекс Облако) коротко: форма в Яндекс Формах открывается с подставленными ответами через `CONTACT_FORM_URL`, а свой сервер возможен на Yandex Cloud Functions, где первый миллион вызовов в месяц бесплатен.
