# Статистика подбора и контакты в таблице для Ольги

Что получает Оля: таблицу, где видно, **сколько людей прошли подбор и с какими запросами**. Если человек сам захочет, он оставляет контакт, и тот добавляется в его же строку.

## Как это устроено
1. Человек проходит подбор. В конце, когда он видит результат, на таблицу уходит **одна строка без имени и контактов**: тема, где ощущается, как давно, насколько мешает, чего ждёт, формат встреч, рекомендованный формат, метка источника (`utm`) и случайный номер прохождения.
2. Если включена форма контакта, под результатом есть необязательный блок «Оставить контакт»: имя (необязательно), телефон или Telegram, галочка согласия (не стоит заранее) и ссылка на политику.
3. Контакт уходит отдельным запросом с тем же номером прохождения и **дописывается в ту же строку**. Если первая отправка не дошла, строка создаётся целиком.

Пока `RESULTS_ENDPOINT` пуст, сайт ничего не отправляет и честно пишет «Ответы нигде не сохраняются». Когда адрес заполнен, текст над подбором и под результатом сам меняется на «Ответы без имени и контактов попадают в обезличенную статистику. Контакт оставляете только вы сами».

Если форма контакта выключена, Оля всё равно получает суть: кнопка «Написать в Telegram» в результате открывает чат с готовым сообщением (тема, подходящий формат, удобный формат встреч).

## Настройка (Google Таблицы, около 10 минут, бесплатно)
1. Создайте Google Таблицу. Откройте Расширения → Apps Script.
2. Вставьте код ниже. Нажмите Развернуть → Новое развёртывание → Веб-приложение. Выполнять от своего имени, доступ: все.
3. Скопируйте адрес веб-приложения в `RESULTS_ENDPOINT` в начале `assets/js/main.js`. Статистика заработает сразу.
4. Чтобы появилась форма контакта, добавьте адрес страницы политики в `PRIVACY_URL`.

```javascript
var SHEET = 'Ответы';
var HEAD = ['Дата', 'ID', 'Тема', 'Где ощущается', 'Как давно', 'Насколько мешает',
            'Чего ждёт', 'Формат встреч', 'Рекомендовано', 'Источник', 'Имя', 'Контакт'];

// Значения, начинающиеся с = + - @, Таблицы считают формулой: экранируем
function safe(v) {
  v = String(v == null ? '' : v).slice(0, 200);
  return /^[=+\-@]/.test(v) ? "'" + v : v;
}

function reply(t) { return ContentService.createTextOutput(t); }

function findRow(sh, id) {
  var n = Math.max(sh.getLastRow() - 1, 1);
  var f = sh.getRange(2, 2, n, 1).createTextFinder(id).matchEntireCell(true).findNext();
  return f ? f.getRow() : 0;
}

function doPost(e) {
  var lock = LockService.getScriptLock();
  lock.waitLock(10000);
  try {
    var d = JSON.parse(e.postData.contents);
    if (!/^[a-z0-9]{8,40}$/.test(String(d.rid || ''))) return reply('bad');
    var ss = SpreadsheetApp.getActive();
    var sh = ss.getSheetByName(SHEET) || ss.insertSheet(SHEET);
    if (sh.getLastRow() === 0) sh.appendRow(HEAD);

    var row = findRow(sh, d.rid);
    var base = [new Date(d.ts), d.rid, safe(d.topic), safe(d.area), safe(d.duration),
                safe(d.interference), safe(d.need), safe(d.meet), safe(d.recommend), safe(d.src)];

    if (d.kind === 'stat') {
      if (!row) sh.appendRow(base.concat(['', '']));
    } else if (d.kind === 'contact') {
      if (row) sh.getRange(row, 11, 1, 2).setValues([[safe(d.name), safe(d.contact)]]);
      else sh.appendRow(base.concat([safe(d.name), safe(d.contact)]));
    }
    return reply('ok');
  } finally {
    lock.releaseLock();
  }
}
```

## Сводная статистика
Создайте второй лист «Статистика» и вставьте формулы (в русской локали разделитель аргументов `;`):

- Запросы по темам: `=QUERY(Ответы!A2:L; "select C, count(B) where B is not null group by C order by count(B) desc label C 'Тема', count(B) 'Человек'"; 0)`
- Рекомендованный формат: `=QUERY(Ответы!A2:L; "select I, count(B) where B is not null group by I label I 'Формат', count(B) 'Человек'"; 0)`
- Сколько человек оставили контакт: `=COUNTA(Ответы!L2:L)`
- Откуда пришли (по меткам `utm`): `=QUERY(Ответы!A2:L; "select J, count(B) where B is not null group by J label J 'Источник', count(B) 'Человек'"; 0)`

Доля оставивших контакт = контакты ÷ все строки. Сколько людей начали подбор и не дошли до конца, видно в Яндекс Метрике по целям `quiz_start` и `quiz_done`.

## Российский вариант без Google (бесплатно, без своего сервера)
Статистика и контакты делятся на два российских сервиса.

**Статистика: Яндекс Метрика.** Цель `quiz_done` отправляет тему и рекомендованный формат как параметры визита без имён и контактов. Они видны в отчёте по параметрам визитов, который можно выгрузить в таблицу. Номер счётчика указывается в `METRIKA_ID`.

**Контакты: Яндекс Формы** (для личного использования бесплатны, данные хранятся в России):
1. Создайте форму: «Имя», «Телефон или Telegram для связи», обязательная галочка согласия со ссылкой на политику, а также короткие текстовые поля «Тема», «Где ощущается», «Как давно», «Насколько мешает», «Чего ждёт», «Формат встреч», «Рекомендовано», «Источник».
2. Для каждого поля откройте настройку предзаполнения и скопируйте идентификатор вопроса ([справка Яндекса](https://yandex.ru/support/forms/ru/pre-fill)).
3. Адрес формы вставьте в `CONTACT_FORM_URL`, идентификаторы в `CONTACT_FORM_FIELDS`, например `{ topic: 'идентификатор', meet: 'идентификатор', recommend: 'идентификатор', src: 'идентификатор' }`. Ключи: `topic`, `area`, `duration`, `interference`, `need`, `meet`, `recommend`, `src`.
4. Ответы приходят на почту или выгружаются файлом на Яндекс Диск, а там открываются как таблица ([обзор сервиса](https://yandex.ru/support/forms/ru/overview)).

После этого под результатом появляется кнопка «Оставить контакт», она открывает форму в новой вкладке с подставленными ответами. Отправляет её сам человек, поэтому скрытой передачи данных нет. Минус: на один шаг больше, чем во встроенной форме, и конверсия в контакт ниже.

**Третий вариант: Yandex Cloud Functions.** Первый миллион вызовов функции в месяц [бесплатен](https://yandex.cloud/ru-kz/services/functions) (нужен платёжный аккаунт). Функция принимает те же JSON-запросы, что и скрипт выше, и пишет их в базу. Подходит, если захотите свой сервер, но сложнее: нужны код, база и способ показать данные Ольге.

## Что стоит знать
- Номер прохождения создаётся заново при каждом «Пройти заново», поэтому один человек, прошедший подбор дважды, попадёт в статистику дважды.
- Ответ веб-приложения браузер не отдаёт сайту (так работает Apps Script). «Отправлено» значит «запрос ушёл без сетевой ошибки». Проверяйте результат в самой таблице.
- Адрес приёма открыт всем, поэтому кто-то может записать в таблицу мусор. Скрипт принимает только корректный номер прохождения и обрезает значения, а форма имеет скрытое поле от ботов. Этого достаточно для небольшого сайта; при росте переходите на свой сервер.
- Ссылки на метки удобно ставить в био Instagram и VK: `https://steelykt.github.io/psychologist-site/?utm_source=instagram`.

## Конфиденциальность (важно)
- Строка статистики без имени и контактов не позволяет узнать человека, но ответы касаются самочувствия. Ставьте её только при условии, что в тексте над подбором стоит уведомление (оно уже есть).
- Контакт вместе с ответами о состоянии это персональные данные, а сведения о психологическом состоянии могут относиться к специальным категориям. Google хранит данные за пределами России. Для хранения контактов обычно нужны российское хранение, письменное согласие и оператор персональных данных. Практичный путь: Яндекс Облако (Cloud Functions и управляемая база) или форма в Яндекс 360. Код сайта менять не придётся, `RESULTS_ENDPOINT` принимает те же JSON-запросы.
- **Это не юридическая консультация.** Политику обработки данных и текст согласия должен проверить юрист.
